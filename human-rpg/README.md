# Human RPG

A browser-local, mobile-friendly life RPG for `Lordofrealms/Lordofrealms.webapps/human-rpg/`.

Target first application version: **0.1.0**. This initial commit records the design before implementation, as requested by the owner on 2026-10-22 (America/Chicago).

## Start here for future work

1. Read the repository root `AGENTS.md` and this directory's `AGENTS.md`.
2. Read `docs/DESIGN.md` for the accepted product contract.
3. Read `docs/DECISIONS.md` for accepted decisions, superseded ideas, and implementation defaults.
4. Read `docs/PLAN.md` for completed and outstanding work.
5. Read `PROJECT_STATE.md` and `HANDOFF.md` for the actual implementation state and next action.

Source control is the durable handoff. Do not rely on chat memory or scratch files. App data, photos, and private financial/health observations never belong in this repository.

## Delivery boundary

Build under this subdirectory, preserving the existing webapps and their storage. Initial use is anonymous, offline-capable, and local to one chosen browser/device. Manual file backup and restore provide portability. Future commercial partner verification and rewards are a separate phase.

The application must distinguish demonstrated/assessed skill, game bonuses, measured observations, and sourced population comparisons. Never invent percentiles, claim that an RPG attribute measures IQ, or treat BMI rank as a health score.
