# Changelog

All notable changes to Tractor Guidance are documented here.

Entries use **Added**, **Changed**, **Fixed**, and **Known issues**. Historical entries are backfilled only where repository history establishes a reliable version boundary.

### Changed
- Completed jobs open in a read-only viewing mode.

### Fixed
- Repaired completed-job summary generation and viewing behavior.

## v32

### Fixed
- Corrected Census JSONP Content Security Policy handling used by address/location search.

## v31

### Added

### Changed
- Advanced the Tractor Guidance shell/assets to v31.

## Earlier development

Repository history before v31 includes substantial guidance, path-recording, nudge/offset, antenna-position, heading/fix, follow/look-ahead, and UI work. Those commits are preserved, but they are not assigned to changelog versions here unless a reliable release boundary can be established.
