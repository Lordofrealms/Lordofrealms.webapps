# Changelog

All notable changes to PDF Editor are documented here.

Entries use **Added**, **Changed**, **Fixed**, and **Known issues**. Historical entries are backfilled only where repository or release history supports them reliably; changes whose exact patch boundary cannot be established are grouped under the nearest reliable release family rather than guessed.

## v0.8.3

### Fixed
- Restored the complete PDF Editor application payload chunk after the stable payload had become incomplete/truncated.

### Changed
- Updated the stable version manifest to v0.8.3 after restoring the complete payload.

## v0.8.2

### Changed
- Published the PDF Editor application payload as versioned payload parts for the stable loader/update path.

## v0.8.1

### Fixed
- Corrected mask background sampling behavior.

## v0.8.x — historical changes with incomplete patch attribution

### Added
- Added a self-updating stable bootstrap/update mechanism.

### Changed
- Improved automatic update handling so document deletions are preserved across updates.

## v0.8.0

### Added
- Added richer text-editing capabilities.

## v0.7.0

### Added
- Added an in-app version indicator.

### Changed
- Improved mask behavior.

### Fixed
- Prevented editor guide boxes from appearing in exported PDFs.

## Earlier versions

Earlier PDF Editor development is preserved in repository history, but release-level notes have not yet been backfilled where version boundaries cannot be established reliably.
